\section{Algorithms and efficiency}
\textit{Source: pp.\ 4--18.}

An \textbf{algorithm} is a well-defined, finite sequence of steps solving a problem. Evaluate its correctness, running time, and memory use. Input size $n$ measures the amount of input, for example the number of array elements.

For a fixed size, different inputs can take different times. Linear search has best-case $\Theta(1)$ time when the first element matches, and worst-case $\Theta(n)$ time when the target is absent or last. An average-case claim requires a model of how inputs are distributed.

\textbf{Experimental analysis} implements the algorithm, measures it on different inputs, and plots time against size. It reflects a particular implementation, machine, compiler, and test set. \textbf{Analytical operation counting} uses pseudocode and a computational model to explain growth independently of those details.

\subsection{The RAM model}
The random access machine model assumes constant-time memory access and primitive operations, such as assignment, comparison, ordinary word-sized arithmetic, and returning a value. Count how often these occur as a function of $n$. This is a modeling assumption: arithmetic on arbitrarily large integers need not be constant time.

Pseudocode omits language details. In these notes, \texttt{<-} denotes assignment and indentation specifies control flow.

\section{Worked count: finding an array maximum}
\textit{Source: pp.\ 15--31, 56--57.}
\begin{lstlisting}
arrayMax(data):                 // require length(data) >= 1
    n <- length(data)
    currentMax <- data[0]
    for i <- 1 to n-1:
        if data[i] > currentMax:
            currentMax <- data[i]
    return currentMax
\end{lstlisting}
\textbf{Invariant:} after processing index $i$, \texttt{currentMax} is the maximum of indices $0,\ldots,i$. Initialization establishes it for $i=0$; each comparison preserves it; termination gives the maximum of the entire array.

There are exactly $n-1$ element comparisons. Assignments to \texttt{currentMax} range from $1$ to $n$, including initialization. With the lecture's counting convention:
\begin{center}
\begin{tabular}{lcc}
\toprule
Component & Best case & Worst case\\
\midrule
Read length and initialize maximum & 4 & 4\\
Loop overhead & $2n$ & $2n$\\
Array access and comparison & $2(n-1)$ & $2(n-1)$\\
Conditional maximum update & 0 & $2(n-1)$\\
Return & 1 & 1\\
\midrule
Total & $4n+3$ & $6n+1$\\
\bottomrule
\end{tabular}
\end{center}
The first element being maximal gives the best case; strictly increasing elements give the worst case. Both are $\Theta(n)$: even the best case must inspect the remaining elements. Exact primitive counts depend on the chosen convention, whereas the linear growth rate does not.

\section{Asymptotic notation}
\textit{Source: pp.\ 33--54, 62--68.}

\subsection{Definitions}
For all sufficiently large integers $n$:
\begin{align*}
f\in O(g)&\iff \exists c>0,\ n_0:\quad 0\le f(n)\le c g(n)\quad(n\ge n_0),\\
f\in\Omega(g)&\iff \exists c>0,\ n_0:\quad 0\le c g(n)\le f(n)\quad(n\ge n_0),\\
f\in\Theta(g)&\iff \exists c_0,c_1>0,\ n_0:\quad
0\le c_0g(n)\le f(n)\le c_1g(n)\quad(n\ge n_0).
\end{align*}
$O$ gives an upper bound, $\Omega$ a lower bound, and $\Theta$ a tight bound. Each denotes a \emph{set of functions}. In particular,
\[
\Theta(g)=O(g)\cap\Omega(g),\qquad
f\in O(g)\iff g\in\Omega(f).
\]

\textbf{Do not confuse a bound with an input case.} $O$ does not mean ``worst case'' and $\Omega$ does not mean ``best case.'' Either notation can describe a best-case, worst-case, or average-case running-time function.

The constant $c$ absorbs multiplicative differences. The threshold $n_0$ allows the bound to ignore finitely many small inputs. Neither must be the smallest possible choice. Constants may not depend on $n$.

\subsection{Proofs by definition}
\begin{enumerate}
\item $25n+2110\in O(n)$: for $n\ge1$,
\[
25n+2110\le25n+2110n=2135n.
\]
Choose $c=2135$ and $n_0=1$.
\item $3n^3+20n^2+5\in O(n^3)$: for $n\ge1$, each smaller power is at most $n^3$, giving an upper bound $28n^3$.
\item $20n^2+4n\in\Theta(n^2)$: for $n\ge1$,
\[
20n^2\le20n^2+4n\le24n^2.
\]
Choose $c_0=20,c_1=24,n_0=1$.
\item $n\log n+204n\in\Theta(n\log n)$: for $n\ge2$,
\[
n\log n\le n\log n+204n\le205n\log n.
\]
The threshold is $2$, since $\log_2 1=0$; the upper bound printed with $n_0=1$ in the slides needs this correction.
\end{enumerate}

To prove that $n^2\notin O(n)$, suppose fixed $c,n_0$ existed with $n^2\le cn$ for all $n\ge n_0$. Choosing an integer $n>\max(c,n_0)$ contradicts $n\le c$.

\subsection{Rules and growth hierarchy}
\begin{itemize}
\item Drop constant factors and lower-order terms when finding a tight growth class: $12n^3+5000n^2+2n^4\in\Theta(n^4)$.
\item Reflexivity: $f\in O(f)$. Transitivity: $f\in O(g)$ and $g\in O(h)$ imply $f\in O(h)$.
\item Additivity: if $f,g\in O(h)$, then $f+g\in O(h)$.
\item Multiplication: if $f_1\in O(f_2)$ and $g_1\in O(g_2)$, then $f_1g_1\in O(f_2g_2)$ for nonnegative functions.
\item $\max(f,g)\le f+g\le2\max(f,g)$, so $f+g\in\Theta(\max(f,g))$ for nonnegative functions.
\end{itemize}
Common growth rates, in increasing order, are
\[
1,\quad\log n,\quad n,\quad n\log n,\quad n^2,\quad n^3,
\quad2^n,\quad n2^n,\quad e^n,\quad n!.
\]
Every fixed-degree polynomial eventually grows more slowly than an exponential with fixed base greater than $1$. Logarithms with fixed bases greater than $1$ differ by only a constant factor. Although $2n+1\in O(n^2)$ is true, $\Theta(n)$ is the more informative bound.

\section{Analyzing loops and sums}
\textit{Source: pp.\ 58--60, 92--94.}
\begin{center}
\begin{tabularx}{\textwidth}{Xl}
\toprule
Pattern with constant work per iteration & Tight time\\
\midrule
Fixed number of iterations, independent of $n$ & $\Theta(1)$\\
Increment $i$ by $1$ or $2$ until reaching $n$ & $\Theta(n)$\\
Multiply positive $i$ by $2$ until reaching $n$ & $\Theta(\log n)$\\
Two independent loops, each of length $n$, nested & $\Theta(n^2)$\\
Inner loop runs $i+1$ times for $i=0,\ldots,n-1$ & $\Theta(n^2)$\\
\bottomrule
\end{tabularx}
\end{center}
Sequential blocks add their costs. For nested loops, sum the inner cost over the outer iterations; simply multiplying the largest bounds can be loose.
\[
\sum_{i=1}^n i=\frac{n(n+1)}2,\qquad
\sum_{i=0}^k r^i=\frac{r^{k+1}-1}{r-1}\quad(r\ne1).
\]
For fixed $r>1$, the geometric sum is $\Theta(r^k)$. For $r=1$ it is $k+1$; for fixed $0<r<1$ it is $\Theta(1)$. Thus the lecture's geometric-growth simplification requires $r>1$.

\section{Prefix averages: eliminate repeated work}
\textit{Source: pp.\ 70--90.}

Given $X[0\ldots n-1]$, compute
\[
A[i]=\frac{\sum_{j=0}^{i}X[j]}{i+1}.
\]
For $X=[5,13,4,8]$, $A=[5,9,22/3,7.5]$.

\subsection{Recompute each prefix: quadratic}
\begin{lstlisting}
for i <- 0 to n-1:
    s <- 0
    for j <- 0 to i:
        s <- s + X[j]
    A[i] <- s / (i+1)
\end{lstlisting}
The additions total $1+2+\cdots+n=n(n+1)/2$, so time is $\Theta(n^2)$.

\subsection{Maintain a running sum: linear}
\begin{lstlisting}
s <- 0
for i <- 0 to n-1:
    s <- s + X[i]
    A[i] <- s / (i+1)
\end{lstlisting}
After adding $X[i]$, the invariant is $s=\sum_{j=0}^iX[j]$. Each iteration is constant time, so the total is $\Theta(n)$. Both versions use $\Theta(n)$ output space and $O(1)$ additional working space. Use real-valued division when fractional averages are needed.

\subsection{Only geometric prefix lengths}
For $n\ge1$, let $k=\lfloor\log_2 n\rfloor$ and output averages for lengths $1,2,4,\ldots,2^k$:
\[
A[i]=\frac{\sum_{j=0}^{2^i-1}X[j]}{2^i},\qquad 0\le i\le k.
\]
Recomputing each prefix now costs
\[
1+2+4+\cdots+2^k=2^{k+1}-1=\Theta(n),
\]
because $2^k\le n<2^{k+1}$. Nested loops therefore need not be quadratic.

A running-sum alternative also takes $\Theta(n)$ time:
\begin{lstlisting}
s <- 0; i <- 0; nextLength <- 1
for j <- 0 to n-1:
    s <- s + X[j]
    if j+1 = nextLength:
        A[i] <- s / nextLength
        i <- i+1
        nextLength <- 2 * nextLength
\end{lstlisting}
The two geometric-prefix methods have the same asymptotic running time, although their constants differ. Output space is $\Theta(\log n)$ as $n$ grows. For an empty input, return an empty output before using a logarithm.

\section{Mathematical reference}
\textit{Source: pp.\ 51--53, 92--94.}
\begin{align*}
a^{b+c}&=a^ba^c,& (a^b)^c&=a^{bc},&a^b/a^c&=a^{b-c},\\
\log_b(xy)&=\log_bx+\log_by,&
\log_b(x/y)&=\log_bx-\log_by,\\
\log_b(x^a)&=a\log_bx,&
\log_bx&=\frac{\log_dx}{\log_db}.
\end{align*}
Logs require positive arguments and bases greater than $0$, unequal to $1$. $\lfloor x\rfloor$ is the greatest integer at most $x$; $\lceil x\rceil$ is the least integer at least $x$. Optional Stirling approximation:
\[
n!\sim\sqrt{2\pi n}\left(\frac ne\right)^n.
\]

\section{Quick review with answers}
\begin{enumerate}
\item Is $77n^2$ in $O(n^3)$, $\Omega(n^3)$, or $\Theta(n^3)$?\\
\textbf{Answer:} only $O(n^3)$ of these three.
\item What about $6n^3+n^2\log n$?\\
\textbf{Answer:} all three, since it is $\Theta(n^3)$.
\item What about $11n^4$?\\
\textbf{Answer:} $\Omega(n^3)$ only.
\item If $f(n)=n^2$ for even $n$ and $n^4$ for odd $n$, which of the three classes applies?\\
\textbf{Answer:} none. The odd subsequence violates an $O(n^3)$ bound; the even subsequence violates an $\Omega(n^3)$ bound.
\item Why does a doubling loop take logarithmic time?\\
\textbf{Answer:} after $k$ iterations its counter is proportional to $2^k$; reaching $n$ requires $k=\Theta(\log n)$.
\end{enumerate}
